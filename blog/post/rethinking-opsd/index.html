特权上下文为何损害思考模型的自蒸馏

阅读于 2026-10-11
自蒸馏思考模型测试时计算

Rethinking On-Policy Self-Distillation for Thinking Models ↗

在线策略蒸馏（on-policy distillation, OPD）曾在多个场景中让学生模型从自身生成轨迹中学习。但当教师模型获得"特权上下文"——完整推理链或最终答案——时，这一范式在思考模型（thinking models）上出现了系统性失效。论文[1]报告了明确的负结果：在五个 Qwen3 与 OLMo 思考模型上，带特权上下文的 OPD 在长推理预算下使平均采样准确率（avg@16）相对下降最高约 17%，恰在思考模型通常最能受益于测试时计算的区域造成损害。

核心张力在于：特权教师本身保持了高 pass@k 性能，轨迹却显著变短；学生只继承了"更短"，却未能继承长预算下的收益。论文提出的 fork suppression（分叉抑制）假设指向一个候选机制：特权信号在高熵分叉位置施加的梯度压力，可能削弱了模型在不确定点探索多条路径的能力。但这一假设目前仅有行为关联证据，尚未通过干预实验提升为因果结论。

在线自蒸馏的基本逻辑与特权扩展

多模态推理中的 M-STAR 框架[2]系统研究了自进化训练的三个设计因子：训练方法（连续继承 optimizer 状态）、奖励模型（过程级 PRM 用于 rerank）、prompt 变化（无标注数据的加入）。该工作观察到探索潜力的衰减（Pass@K 持续下降）与性能饱和相关，并提出 Reward-Pass@2 作为平衡 exploration 与 exploitation 的监控指标。如果训练信号过早将模型推向确定性输出，多样性的丧失会限制长预算场景下的收益。

特权上下文 OPD（OPSD）引入了不对称信息：教师模型提供蒸馏信号时可以访问学生不可见的上下文 cc——例如问题的完整解答步骤或最终答案。形式上，教师分布变为 πθ(y∣x,c)\pi_\theta(y|x, c)，学生在评估时仍是 πθ(y∣x)\pi_\theta(y|x)。

负结果的实证边界

在 OpenThoughts 训练设置下，五个模型一致显示：无特权的 OPD（c=∅c = \emptyset）略微提升或保持学生性能，而 OPSD（c=c = 完整解答或仅最终答案）在长预算下导致下降，且下降幅度随评估预算增长而加剧。这一预算依赖性恰好与思考模型的设计意图相悖：测试时计算本应在长预算下带来更大收益。

特权密度同样影响损害程度：提供完整解答（密集特权）比仅提供最终答案（稀疏特权）造成更严重的下降，暗示损害与"模型在多少位置接收到特权信号"有关。

Countdown 设置的结果更为混合：Qwen3-4B-Think 仍出现微降，但 OLMo-7B-Think 反而微升。一种待验证的解释涉及 Countdown 任务的域内性质（训练与评测分布接近）与数据规模较小，但这一解释未被独立验证。混合结果削弱了"OPSD 必然损害思考"的普遍性主张，提示条件边界仍需厘清。

关键对照实验是：在训练 rollout 中关闭思考标记（forcing immediate answers），学生性能几乎不变（0.591 → 0.590）。

分叉抑制假设：关联还是因果？

论文在 §4 提出了机制假设：fork suppression。思考模型在推理过程中会遇到分叉位置（forking positions）——即模型对下一 token 的熵较高、存在多条可行路径的时刻。在这些位置，特权教师因看到答案而倾向于选择某一条确定路径，生成的轨迹中思考标记密度下降、熵降低。学生接收带特权的蒸馏信号时，可能被训练为在高熵点过早锁定（lock in），从而削弱了探索能力。

论文提供的证据包括：

  • OPSD 训练后模型的 fork 率（高熵位置占比）下降
  • 逐 token 的 log-ratio 出现符号反转（sign reversal）
  • 思考标记密度与 fork 率同步下降

但这些证据都是行为关联：三个现象同时发生，并不能排除共同原因或反向因果。论文未做干预实验——例如在 OPSD 损失中对高熵分叉位置的 token 施加梯度掩码或重加权，检验长预算性能能否恢复。因此 fork suppression 应视为待验证推断，而非已确立机制。

Coverage Principle[3]则从理论角度指出，预训练模型在下游任务上的成功取决于其对目标分布的覆盖度（coverage profile），而非仅仅交叉熵。该工作证明 MLE 隐式优化覆盖度且泛化快于交叉熵。这一视角为理解 OPSD 失效提供了互补解释：特权上下文可能将学生推向一个在测试分布上覆盖度不佳的子空间。

可验证的下一步

阅读笔记围绕 fork suppression 假设列出了三个可验证行动：

  1. 最小对照复现：固定学生与数据，比较 c=∅c = \emptyset 与 c=goldc = \text{gold}，分别在 4k 与 32k 预算上报告 avg@16，验证预算依赖是否独立成立。
  2. 长度归一化的配对比较：从训练前后的评测 rollout 中提取 fork 率与思考标记密度，做长度归一化后确认标记下降不由轨迹整体变短驱动。
  3. 梯度干预：在 OPSD 损失中对高熵分叉位置施加梯度掩码或信号重加权，检验长预算性能能否恢复——这是将 fork suppression 从关联推向因果的最小干预。

这三步中，第三步是关键：如果性能恢复，fork suppression 升级为可操作的因果假设；如果不恢复，需要重新审视其他混淆项（例如特权内容本身 vs. 信号施加位置）。

实践边界与开放问题

当前证据支持的结论是有条件的：

  • 在长推理预算+ 密集特权上下文 + OpenThoughts 类异质 prompt 分布上，OPSD 对 Qwen3/OLMo 思考模型造成损害。
  • 损害不由"压制思考"本身引起（关闭思考的对照实验性能不变），而与特权信号的交互方式有关。
  • Countdown 的混合结果提示域内评估或小数据规模可能改变失效模式，但具体边界未明。

开放问题包括：

  • 若特权信号只施加在低熵锁定位置，思考能力是否仍受损？这能拆分"特权内容"与"施加位置"两假设。
  • 提高采样温度或加入熵奖励能否抵消损害？还是症结在信用分配方向而非探索量？
  • 步骤级 PRM rerank 能否修复 OPSD 轨迹的探索缺陷？

从更广视角看，这一负结果与 Coverage Principle 的理论框架呼应：next-token prediction 的成功依赖于对下游分布的覆盖度，M-STAR 的动态监控（Reward-Pass@2 + 自动调温）提供了一种实践路径：在在线训练中持续追踪探索指标，并在探索衰减时主动干预。将这一思路引入思考模型的自蒸馏，或许能在享受在线训练收益的同时，避开特权信号的陷阱。

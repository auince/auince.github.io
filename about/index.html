四川省消防总队智慧消防系统

面向巡检样本稀缺、细粒度隐患识别困难与法规依据匹配复杂的问题，开发消防垂直领域大小模型群，用于火场态势感知与消防隐患识别。

  • 数据与标注：收集 1,196 组实采巡检样本，结合开源图像与局部缺陷仿真，搭建“人工提示 + 模型生成”“模型预标注 + 人工复审”的协同流程。
  • 法规 RAG：整合 70 余份法规、标准与案例，构建标题—正文双向索引，融合 BM25、稠密检索、RRF 排序与 Agent 查询改写。
  • 模型后训练：基于 Qwen3.5-9B 进行 LoRA 监督微调，设计格式、隐患标签和最终结论奖励，在 SFT 基础上引入 GRPO。
项目结果

327 张测试图像上的合规判定准确率：53.12% → 81.25%（SFT）→ 90.63%（RLVR）。法规检索 Top1 命中率从 61.51% 提升至 74.21%，Top5 准确率从 78.17% 提升至 92.06%。

主研成员 · 联合华西医学院2025.10 — 2026.07

口腔临床诊断辅助评估系统

在真实病患数据上构建口腔临床诊断辅助评估 Agent 系统，支持根管炎症、牙隐裂等多种病症的病症提取、风险评估及治疗难度评估。

  • Skills–Agent 两层架构：将病历图文解析、信息审校、问题标记、知识检索封装为四个 Skills，由 LeaderAgent 与多个病症专业 Agent 按任务调用。
  • 协同调度：LeaderAgent 拆解任务并路由至对应 Agent，进行病历二次校对，通过共享上下文同步状态并统筹回答。
  • 领域后训练：基于口腔医学书籍和 1,954 条真实病历构建分析及评估数据，使用 Qwen3-VL-8B-Instruct 进行继续预训练、LoRA 监督微调与 GRPO 优化。
项目结果

病症提取准确率从 55.10% 提升至 92.03%，风险评估准确率从 39.68% 提升至 89.30%。双卡 4090 环境下，单 Agent 响应 15–40 秒，单次回答 80–120 秒。
